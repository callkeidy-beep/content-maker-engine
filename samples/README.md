# 샘플 메일 20건 — 기대 결과표

모든 기관·인물·주소·전화번호는 가상이다. 도메인은 `.invalid`로 끝난다.
각 파일 헤더에 `X-Sample-Account`(naver/daum)와 `X-Sample-Folder`가 있다. SampleProvider는 이 값으로 두 계정을 흉내 낸다.
수신 시각은 2026년 11월 24~27일(KST). 1단계 테스트는 '오늘'을 2026-11-27로 고정해 돌린다.

## 트렌드 기획에서 기대하는 흐름 (근거가 맞으면 다른 표현도 정답)

- 관객·관람객 '최다·돌파' 발표가 겹친다: 05, 14, 15, 16
- 가람시 공연장 지원이 여러 갈래로 나온다: 08, 13, 18
- 신작 영화 겨울 개봉: 01/03, 20

## 추가 취재 질문 기획에서 기대하는 예시

- 10(환불 지연): 주최사 하늘기획의 환불 계획, 예매처 약관상 책임, 피해 규모 확인
- 06(시청 1위): '자사 집계'의 기준, 전체 가입자 대비 비율
- 16('개관 이래 최다'): 무료 관람 행사 포함 여부, 집계 기준 변경 여부
