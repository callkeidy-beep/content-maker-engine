# 오늘의 후보 12 — 점수와 학습

## 1. 점수 항목 (각 0~5)

| 키 | 이름 | 산출 방식 |
|---|---|---|
| timeliness | 시의성 | 수신 시각, 행사·발표일과의 거리. AI가 판정, 규칙으로 보정 |
| impact | 독자 영향력 | 영향을 받는 사람 수, 돈·생활과의 연결. AI 판정 |
| exclusivity | 독점성·희소성 | 같은 자료가 여러 곳에 갔는지(일괄 배포 문구), 제보 여부. 제보는 +1 |
| fit | 매체 적합도 | 기본 매체의 분야 설정(publication.yaml)과의 일치도 |
| visual | 시각 자료 | 사용 가능한 사진 수·품질. 0장=0, 1장=2, 3장 이상 고화질=5 |
| embargo | 엠바고 시점 | 오늘 해제=5, 이미 해제=3, 내일 이후=1 |
| follow_up | 후속 취재성 | 취재 질문 기획에서 나온 질문의 수·무게 |
| numbers | 숫자·데이터 | 그래픽으로 만들 숫자가 있는지 |
| duplication | 중복도(감점) | 최근 7일 비슷한 자료·기사 수 |

## 2. 총점

```
base = Σ (w_k × s_k) / 5 × 100        # k ≠ duplication, Σw_k = 1
total = base + category_bias[c] − duplication_penalty
duplication_penalty = s_duplication × config.penalty_per_point (기본 4)
```

- 총점은 0~100으로 자른다.
- 엠바고가 내일 이후면 후보에는 올리되 '잠김' 표시.
- sensitive_class가 none이 아니면 후보에 올리되 'AI 초안 제한' 표시.

## 3. 후보 선정

1. 지난 48시간(설정) 안에 들어온 자료와 기획을 모은다.
2. 이미 승인·폐기된 자료는 뺀다.
3. 같은 자료에서 나온 기획은 가장 점수 높은 하나만 main 후보로 둔다.
4. 총점순 상위 10개 = main.
5. 탐색 2개 = explore:
   - 최근 30일 편집자 평균 평점이 낮거나 평가 수가 적은 분야에서 고른다.
   - 그 분야 안에서 base 점수가 가장 높은 자료.
   - 같은 분야에서 2개를 고르지 않는다.
6. 한 분야가 main의 40%(4개)를 넘지 않게 한다. 넘치면 다음 순위로 바꾼다.
7. 후보마다 추천 이유 한 줄을 만든다(prompts/recommend_reason.md).

후보가 12개보다 적으면 있는 만큼만 보여주고 "자료 부족"이라고 쓴다. 채우려고 억지로 만들지 않는다.

## 4. 학습 (평가 반영)

평가가 들어오면 매일 추천 30분 전(기본 06:30)에 가중치를 갱신한다.

### 4-1. 가중치
```
target = (rating − 1) / 4                   # 0~1
pred   = base / 100                         # 0~1
error  = target − pred
w_k ← w_k + lr × error × (s_k / 5)          # lr 기본 0.05
w_k ← clamp(w_k, w_min, w_max)              # 0.03 ~ 0.40
w ← w / Σw                                  # 다시 합 1
```

### 4-2. 분야 보정
```
category_bias[c] ← category_bias[c] + lr_bias × (rating − 3)     # lr_bias 기본 1.0
category_bias[c] ← clamp(−15, +15)
```

### 4-3. 태그 반영
- adopt: rating에 +0.5 (최대 5)
- drop: rating에 −0.5 (최소 1)
- follow: 해당 자료의 follow_up 점수를 다음 계산에서 +1

### 4-4. 안전장치
- 평가가 누적 10건이 넘기 전에는 가중치를 바꾸지 않는다. 분야 보정만 반영.
- 하루 한 번만 갱신한다. 한 번에 각 가중치 변화는 ±0.05를 넘지 않는다.
- 갱신마다 weight_versions에 새 버전을 저장한다. 이유 문장 포함
  (예: "시각 자료 가중치 0.10→0.13: 사진 많은 후보에 높은 평점 7건").
- 화면에서 초기화(config 기본값)와 특정 버전 복원.

## 5. 나중 단계

평가가 200건 이상 쌓이면 회귀 모델로 바꿀 수 있다. 인터페이스(`score(item) -> (total, features)`)를 지키면 교체 가능하게 만든다.
