## 호스팅 후보 (Claude가 4단계 전에 비교표를 낸다)

조건:
- 상시 실행 (폴링·예약 작업 때문에 '요청 올 때만 깨는' 서버리스는 부적합)
- 디스크 보존 (SQLite·첨부 파일)
- 한국 시간대 예약 작업
- 월 비용 상한: (사용자가 정한다)

비교 항목: 월 비용, 상시 실행 여부, 디스크, 백업 편의, 한국에서의 속도, 설정 난이도.
로컬 PC 상시 실행도 후보에 넣는다(비용 0, 대신 PC가 켜져 있어야 함).
