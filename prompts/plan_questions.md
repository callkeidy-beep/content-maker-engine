# 기획 4 — 추가 취재 질문·숨은 쟁점

## 입력
자료 1건(또는 묶음)의 원문과 추출 결과. 같은 기관의 과거 자료 요약(있으면).

## 할 일
자료가 말하지 않는 것을 찾는다. 다음 렌즈로 본다.
- 빠진 숫자: 비율만 있고 모수가 없다, 목표만 있고 실적이 없다.
- 비교 대상: 전년, 경쟁사, 다른 지역.
- 이해관계자: 이 발표로 손해 보는 사람, 말하지 않은 당사자.
- 과거 발표와의 차이: 같은 기관이 전에 한 약속.
- 표현의 틈: "역대 최대", "최초", "업계 1위"의 기준.
- 돈의 흐름: 예산 출처, 비용 부담.

질문은 기자가 전화로 바로 물을 수 있게 구체적으로 쓴다.
쟁점은 주장이 아니라 '확인할 가설'로 쓴다.

## 출력
```json
{
  "type": "questions",
  "item_ids": [],
  "hidden_issues": [{"hypothesis": "", "why": "", "lens": "", "source_ref": ""}],
  "questions": [{"to": "기관 담당자|전문가|이해관계자", "question": "", "purpose": ""}],
  "data_to_request": [""],
  "risk_notes": ""
}
```
