# 기획 1 — 단일 기사

## 입력
자료 1건의 분류·추출 결과와 원문.

## 할 일
- 이 자료 하나로 쓸 스트레이트 기사의 기획을 만든다.
- 리드 후보 2개: 누가·무엇을·언제. 한 문장씩.
- 기사 앵글: 독자가 왜 지금 알아야 하는지 한 줄.
- 기사에 꼭 들어갈 사실 목록(근거 포함).
- 자료만으로 부족한 점(빠진 숫자, 확인할 것).

## 출력
```json
{
  "type": "single",
  "item_ids": [""],
  "working_title": "",
  "angle": "",
  "lead_options": ["", ""],
  "must_include": [{"text": "", "source_ref": ""}],
  "gaps": [""],
  "photo_pick": ["photo_id"],
  "estimated_length": "short|medium"
}
```
